# stripchat-pp-my_module

> 将 `Cargo.toml` 中的 `name` 和 `[[bin]].name` 改为你的模块 ID，
> 然后修改 `src/main.rs` 中的 `DESCRIBE` 常量和 `run()` 函数。
>
> Change `name` and `[[bin]].name` in `Cargo.toml` to your module ID,
> then edit the `DESCRIBE` constant and `run()` function in `src/main.rs`.

A post-processing module for [StripchatRecorder](https://github.com/ChanTrail/StripchatRecorder).

## 快速开始 / Quick Start

使用此模板时需要修改以下三处，**其他文件无需改动**：

Only three things need to be changed when using this template — **no other files need editing**:

1. **`Cargo.toml`** — 将 `name` 和 `[[bin]].name` 改为你的模块 ID（小写字母、数字、下划线）  
   Change `name` and `[[bin]].name` to your module ID (lowercase letters, digits, underscores)

2. **`registry.json`** — 填写 `description` 和 `tags`（其余字段由 Release CI 自动生成）  
   Fill in `description` and `tags` (all other fields are auto-generated by the Release CI)

   ```json
   {
     "description": "你的模块功能描述 / What your module does",
     "tags": ["notify", "upload"]
   }
   ```

3. **`src/main.rs`** — 修改 `DESCRIBE` 中的参数定义和 `i18n`，实现 `run()` 函数中的处理逻辑  
   Update params and `i18n` in `DESCRIBE`, implement processing logic in `run()`

> `id`、`name`（显示名）、`version` 均从 `Cargo.toml` 自动读取，无需手动填写。  
> `id`, display `name`, and `version` are all read from `Cargo.toml` automatically.

## 发布 / Release

### 首次配置 / First-time setup

为仓库添加 `RELEASE_PAT` secret：

1. GitHub 头像 → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. 点 **Generate new token (classic)**，勾选 **repo** 权限，点 **Generate token**
3. 复制生成的 token（`ghp_xxx...`，只显示一次）
4. 进入模块仓库 → **Settings → Secrets → Actions** → **New repository secret**
5. **Name** 填 `RELEASE_PAT`，**Secret** 粘贴 token，点 **Add secret**

Add a `RELEASE_PAT` secret to the repo:

1. GitHub avatar → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. Click **Generate new token (classic)**, check **repo** scope, click **Generate token**
3. Copy the token (`ghp_xxx...`) — shown only once
4. Go to the module repo → **Settings → Secrets → Actions** → **New repository secret**
5. Set **Name** to `RELEASE_PAT`, paste the token into **Secret**, click **Add secret**

### 首次发布 / First release

```bash
# 1. 确保上述三处改动已提交 / Commit the three changes above
git add Cargo.toml src/main.rs registry.json
git commit -m "feat: initial module implementation"
git push origin master
# CI 自动推 tag → 触发 Release workflow → 生成完整 registry.json → 创建 GitHub Release
# CI auto-pushes tag → triggers Release workflow → generates registry.json → creates GitHub Release
```

Release 完成后，向 [StripchatRecorderCommunity](https://github.com/ChanTrail/StripchatRecorderCommunity) 提一次 PR，在中央索引的 `registry.json` 末尾追加：

After the Release completes, open a PR to [StripchatRecorderCommunity](https://github.com/ChanTrail/StripchatRecorderCommunity) and append to `registry.json`:

```json
{ "id": "00000NNN", "repo": "https://github.com/your-username/stripchat-pp-your-module" }
```

### 后续版本升级 / Subsequent releases

只需修改 `Cargo.toml` 中的 `version` 字段并 push，其余全部自动完成：

Just bump `version` in `Cargo.toml` and push — everything else is automatic:

```bash
# 修改 Cargo.toml 中的 version 后 / After bumping version in Cargo.toml
git add Cargo.toml
git commit -m "chore: bump version to 1.1.0"
git push origin master
```

CI 自动完成：check/clippy/test → 推 tag → 多平台编译 → 写回 `registry.json` → 创建 GitHub Release。  
**无需向中央索引再次提 PR。**

CI automatically handles: check/clippy/test → push tag → multi-platform build → update `registry.json` → create GitHub Release.  
**No further PR to the central index needed.**
